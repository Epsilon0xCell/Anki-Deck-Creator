The repo

Creates Anki decks (.apkg files) from a plain text file of flashcards, plus three small helper scripts that query a running Anki instance through the AnkiConnect add-on.

What it is

Anki Deck Creator: 11 files, 744 counted lines across Text 332, Python 293, YAML 63. One job, done in the open, in files you can read.

The biggest piece

flashcards.txt carries the most lines. If the project grows, that file is where the growth lands first, for better or worse.

The honest gap

No test files yet. That is the honest gap, and the roadmap in the visuals folder says what the first one should cover.

Run it

The repo README has the exact commands for this one. The shape is the shape for most of my projects: clone it, read the top file first so you know what will happen, then run it on something you do not mind breaking.

$ git clone https://github.com/Epsilon0xCell/Anki-Deck-Creator.git
$ cd Anki-Deck-Creator
